# Лендинг Lumi Vinetka

Статичный сайт: `index.html`, `styles.css`, `app.js`, `content.js` и `calc.js`. Сборка не
нужна — папку можно выложить на любой хостинг (Netlify, GitHub Pages, Vercel, обычный хостинг).

Посмотреть локально:

    python -m http.server 5173

и открыть http://127.0.0.1:5173.

## Что и где менять

Всё содержимое — в `content.js`: контакты, каталог, пакеты, работы, команда,
локации, отзывы, вопросы. Фото кладутся в `landing/img/`,
путь вписывается в поле `img`. Пока поле пустое, на месте фото рисуется заглушка.

## Калькулятор

Цены, пороги и правила расчёта — в `calc.js` (`CONFIG` и `calcPrice`). Тесты по
кейсам из ТЗ:

    node --test

`calculator-draft.html` — исходный набросок калькулятора, на сайте он уже встроен.

## Заявки → CRM

Форма отправляет заявку в ту же Google Таблицу, с которой работает бот. Скрипт
добавляет на лист «Заказы» строку со статусом «Лид»: школа и класс, контакт,
телефон, количество учеников, а в «Примечания» — пакет и расчёт из
калькулятора. Бот видит новую строку при следующем опросе и присылает «Новый лид»
тем, у кого роль «Приём заявок». Дальше заказ идёт по обычному циклу CRM.

Mac с ботом при этом в интернет открывать не нужно.

Подключение (один раз):

1. Откройте таблицу CRM → «Расширения» → «Apps Script».
2. Удалите всё в редакторе и вставьте содержимое `crm/apps-script.gs`. Сохраните.
3. «Начать развёртывание» → «Новое развёртывание» → тип «Веб-приложение».
   - Выполнять от имени: «Я».
   - Доступ: «Все».
4. Разрешите доступ к таблице, когда Google спросит.
5. Скопируйте адрес веб-приложения (заканчивается на `/exec`) и вставьте в
   `content.js` → `crmEndpoint`.

Если позже поменяете скрипт, разверните его заново: «Управление развёртываниями» →
карандаш → «Новая версия». Адрес останется тем же.

Пока `crmEndpoint` пустой, форма показывает ошибку и предлагает написать в WhatsApp.
